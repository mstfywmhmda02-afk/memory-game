# لعبة الذاكرة 🧠

لعبة كروت ذاكرة عربية، أوفلاين بالكامل، للأندرويد. Arabic offline memory card game.

## التحميل والتثبيت
1. نزّل `memory-game.apk` من صفحة [Releases](../../releases).
2. على الموبايل فعّل "التثبيت من مصادر غير معروفة" وثبّت الملف.

أو افتح `index.html` في أي متصفح من غير ما تثبّت حاجة.

## المميزات
- 3 مستويات: سهل ووسط وصعب
- عداد حركات ومؤقت
- أفضل نتيجة محفوظة على الجهاز

## ملاحظات مهمة ⚠️
- الـ APK لسه متجربش على موبايل حقيقي.
- الكروت بتعرض إيموجي؛ ممكن مايظهروش صح على بعض الأجهزة (لسه متأكدناش).
- الـ APK موقّع بمفتاح مؤقت: أي تحديث جاي ممكن يحتاج تمسح التطبيق وتثبّته من الأول، والنتائج المحفوظة هتتمسح معاه.
- التطبيق أوفلاين: مفيش إعلانات ولا إنترنت ولا تتبع.
